# Sensor Daemon

## Building

Theres a build script in Haskell which can be run with this command:

```bash
./build.hs
```

If you dont have a Haskell enviornment set up you can just install GHC with your package manager.

Using Homebrew:

```bash
brew install ghc
```

Using APT:

```bash
sudo apt install ghc
```
